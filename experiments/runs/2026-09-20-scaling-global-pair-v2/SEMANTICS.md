# Comparison scope and proof obligations

Both strategies use the same explicit minimum chain and independent per-entry next-state equations, with the original sequential block and original target retained. Only NUM_REQ changes. The sizes tested are powers of two at least 4, so an arbitrary log2(N)-bit preservation index ranges over exactly the valid entries. Rank widths remain clog2(N+1), including the N sentinel. All accepted proofs use EBMC 6.0, default MiniSAT, 4-induction, and a 60-second cap per call. Runs are sequential to avoid competition for CPU. Discovery and fresh-process replay are separate; one timing observation per phase is not a statistical performance estimate.

The shared preservation harness proves a scan-step identity plus N update/frame identities and N grant identities for arbitrary rank/priority values, without assumptions. The original first loop reads the unchanged copy of ranks, so its scan recurrence is precisely the explicit chain. The second loop writes each index once and reads only that index, so the per-entry update identities compose. The state relation is identity. This composition is a reviewed source-level argument, not a monolithic machine-checked sequential equivalence certificate.

The global invariant enumerates N rank bounds, N(N-1)/2 rank inequalities, and one guarded requester-validity clause. The pair invariant uses the latched requester pair when chosen, and the validated raw pair (or fallback 0,1) otherwise. It asserts valid/distinct pair indices and bounded/distinct pair ranks. Its six comparison clauses do not grow with N, though multiplexers for reading the two ranks and the full circuit do grow.

Before chosen, the reachable ranks are the reset identity permutation. The prospective pair therefore has distinct valid ranks regardless of current raw inputs. On latching, the same pair is selected and its rank update preserves boundedness and inequality. After latching the indices remain stable. For any priority, the update maps rank equal to priority to N-1, greater ranks to rank-1, and smaller ranks to themselves. This is injective on ranks 0..N-1 (and is the identity there if priority is at least N). These observations motivate the helper; the complete sequential helper is proved independently by EBMC with no generated assumptions.

The target assumes only the independently proved helper. A granted requester's rank equals the minimum; another requesting rank is no smaller; inequality between the two tracked ranks makes the comparison strict. --reset main.rst imposes reset initially and no later resets. Uninitialized selected indices are harmless before chosen; no other input constraints are added.

For every size and strategy, the diagnostic negates the active target antecedent together with the other request. Its base-case counterexample witnesses consistency, reset release, and a nonvacuous strict comparison. Diagnostic failure is never a failed target.

This compares explicit global invariants with a property-directed tracked-pair invariant on the full N-entry design. It does not implement a parameter-independent abstract two-register arbiter or claim a proof for all N from one solver call. Every N gets its own recorded proof and audit. Preservation cost is counted in full for each strategy's reusable total, even though the identical shared preservation call is executed only once per phase and N.

An initial harness-generation attempt used cascading width substitutions, creating incorrect dimensions for N=4. It was interrupted and excluded. The v2 generator uses placeholders; all v2 evidence is freshly recorded.
