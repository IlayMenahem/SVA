\section{Agent}
\label{sec:harness}

The LLM must have agentic and reasoning capabilities, along with a context window larger than 128k tokens.

The full harness includes
\begin{itemize}
    \item Pi as the harness.
    \item The skill 'accelerate-sva-proofs'.
    \item Headroom for context compression.
    \item Memory management that clears duplicates in the context window.
\end{itemize}
