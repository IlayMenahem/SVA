\section{Harness}
\label{sec:harness}

The full harness includes

\begin{itemize}
    \item The prompt generation will include a skill file to help the LLM methodologically work like a verification engineer.
    \item Use lean-context to manage context. The agent must have permissions to read the design, assertion, and .tcl files. It should be able to write new assertion, auxiliary code, and .tcl files. The .tcl file contians the assume-and-prove commands and the abstractions.
\end{itemize}
