\section{Model}

This work can use a standard LLM architecture; we plan to start from an open-source pretrained LLM.
The model should have agentic and reasoning capabilities, and a context window larger than 32k tokens since the design files can be quite large.

Candidate:

\begin{itemize}
    \item \textbf{Qwen3.6-36B-A3B} ($36$B total, $\sim$$3$B active) --- MoE; primary choice for the full PPO run.
\end{itemize}
