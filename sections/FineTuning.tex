\section{Fine-Tuning}
\label{sec:finetuning}

Reinforcement learning explores efficiently only from a competent starting policy.
We therefore fine-tune the base LLM on a domain corpus to give it fluency in
SystemVerilog, SVA, and the assume-guarantee contract structure before the RL
stage (Section~\ref{sec:rl}).

\subsection{Data Sources}
\label{sec:ft-sources}

No single public dataset labels assume-guarantee pairs as such: existing SVA
corpora emphasize \texttt{assert property} generation but rarely include the
paired \texttt{assume property} statements that define environment constraints.
We therefore compose the corpus from complementary sources.

\subsection{Staged Fine-Tuning}
\label{sec:ft-stages}

We fine-tune on this combined corpus in two stages: the first covers SystemVerilog and SVA syntax and temporal operators; the second covers the assume-guarantee contract structure.
