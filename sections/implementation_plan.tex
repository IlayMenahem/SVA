\section{Implementation Plan}
\label{sec:implementation-plan}

\begin{itemize}
    \item \textbf{Phase 1: Environment and Prover Setup.}
    Implement the typed action parser, proof-state ledger, prover adapter, and
    trajectory logger on 20--50 small verified instances. The phase is complete
    when runs are deterministic under fixed seeds, malformed actions are
    rejected, and an independent replay check confirms that no target is
    accepted with an unresolved obligation.

    \item \textbf{Phase 2: Dataset Construction and Baselines.}
    Extract verified design--property pairs, normalize their build scripts,
    deduplicate them by design, and freeze design-level training, validation,
    and test splits. Run the prover alone, a single-shot frozen LLM, and a
    frozen LLM with verifier feedback under identical time limits. The phase is
    complete when every retained instance is reproducible and baseline proof
    time, timeout status, and resource use have been recorded.

    \item \textbf{Phase 3: Supervised Fine-Tuning.}
    Build the two-stage corpus described in Section~\ref{sec:finetuning} and
    fine-tune the dense bring-up model first on SystemVerilog/SVA syntax and
    then on assume-guarantee examples and valid proof actions. The phase is
    complete when the fine-tuned model improves action-schema validity and
    discharged-obligation rate over the frozen model on the validation split.

    \item \textbf{Phase 4: Restricted RL Pilot.}
    Train using only \texttt{ADD\_LEMMA} and \texttt{RETRACT} actions on small
    designs with short timeouts. Tune the reward coefficients only on the
    training and validation splits. The phase is complete when at least one
    replicated run improves held-out validation solve rate or median proof time
    over supervised fine-tuning alone without increasing unsound acceptances.

    \item \textbf{Phase 5: Hierarchical and Transformational Actions.}
    Add interface contracts, cutpoints, abstractions, and blackboxing one at a
    time, together with the proof obligations required by
    Section~\ref{sec:rl}. Each action is retained only if its adapter passes
    soundness replay tests and improves validation performance; otherwise it is
    excluded from the final action space.

    \item \textbf{Phase 6: Full Training Run.}
    Scale the validated configuration to Qwen3.6-36B-A3B and the full curriculum.
    Freeze the model, reward coefficients, prover configuration, and stopping
    rule before test evaluation. Checkpoints are selected using validation
    solve rate under a fixed end-to-end compute budget.

    \item \textbf{Phase 7: Final Evaluation.}
    Compare the prover-only, frozen-agent, fine-tuned, restricted-RL, and full
    systems on the untouched test designs. Report solve rate, end-to-end proof
    time, verifier calls, CPU/GPU-hours per solved target, proof-DAG size, and
    confidence intervals, together with ablations and a categorized failure
    analysis. The project is complete when the experiment can be reproduced
    from a clean environment and every reported successful proof passes
    independent replay.
\end{itemize}
